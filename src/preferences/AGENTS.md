# `src/preferences/` — GTK4 + Adwaita preferences application

Standalone preferences window. Uses GTK4 and libadwaita for a modern look.

The four pages come from `g_paste_gtk_preferences_pages_new()`, which two things consume: `GPasteGtkPreferencesWidget`, the embeddable view stack with a switcher and a breakpoint of its own, and `g_paste_gtk_preferences_pages_list()`, an introspectable `GPtrArray` of the same pages for a caller that has a preferences window already — which is what the GNOME Shell extension has. The pages bind to a `GPasteSettings` without holding a reference, so whoever hands them out keeps one alive: the widget in its private struct, the list on each page's qdata. The behaviour page's **GNOME Shell group** is the one thing on any of them that is not simply built and shown: whether the extension is installed is something only the shell knows, so the group is added hidden, in the place it belongs between the others, and revealed from the reply to `g_paste_util_has_gnome_shell_extension()` — an `org.gnome.Shell.Extensions.GetExtensionInfo` call with `NO_AUTO_START` (the shell is not activatable, so a session running none fails at once instead of waiting out the timeout), which answers an *empty dictionary* for a uuid it does not know rather than an error, so what says the extension is there is the dictionary having anything in it. `g_paste_util_has_gnome_shell()` cannot answer that question: it only says the shell's *schema* is installed, which a session running no shell still has — and a switch offered on that basis writes GPaste into `enabled-extensions` and changes nothing anybody can see. Both failure paths `g_debug()` what went wrong before hiding the group, since an absent group looks the same whichever way it got there. The question is asked with a `GCancellable` the group itself owns and its `::destroy` cancels. The callback holds only a `GWeakRef` to the group, so releasing the page can destroy the group and cancel a shell that is not answering; the callback finishes the query even when the group is gone.
